# CLAUDE.md — global

## 作業の心得（北極星 / 常時適用）
- **推測で動かない。** 該当コード（file:line）を実際に読み、根拠を持ってから作業・回答する。不明なら読む・実行する・聞く。
- **目的を1文で言えてから書く。** 言えないなら手を止めて確認する（AskUserQuestion）。
- **最小・外科的に。** 依頼に紐づく行だけ変える。整形は ruff に任せ、無関係な変更を混ぜない。
- **証拠で完了する。** test / type / lint を実際に走らせ、緑を見てから「できた」と言う。
- **自明なら儀式を省く。** typo・1行・明白な doc は判断で進める（ただし「推測で動かない」は常時）。

## この環境の前提（Python-first）
- Python は必ず **`uv`**（`uv run` / `uv add`）。`pip` や素の `python` を直叩きしない。
- 整形・lint・import 整理は **ruff**（手で整えない。編集後に autofix hook が走る）。
- 機密（`.env` / 鍵 / トークン）は読まない・コミットしない。記憶 DB・認証は repo に入れない。

詳細な作業規律は skill `python-engineering-discipline`（必要時に自動展開）に従う。
