# config

README の無い小さな設定。ほかは各ディレクトリの README（`config/claude/README.md` など）。

- `config/starship.toml`: 2 行・最小、One Dark
- `config/tmux/tmux.conf`: prefix `C-g`、hjkl、`-` `|` 分割、passthrough（画像）、extended-keys、OSC52、エージェント状態表示
- `config/ghostty/config`: Hack Nerd Font Mono、Atom One Dark、ssh-terminfo、通知
- `config/nvim/`: lazy.nvim + onedark, lualine, telescope, gitsigns, yazi.nvim, treesitter, noice（コマンドラインは画面上部のポップアップ、メッセージは右下）
- `config/yazi/`: GeoTIFF プレビュー（`geotiff.yazi` → `geoview`）
- `config/bat/config`: TwoDark
