# Principles

Apply these to every task.

## Philosophy
- Think before coding, keep it simple, make surgical changes, and define clear success
  criteria then verify against them. (Karpathy-style discipline.)
- The best code is the code you never wrote: avoid writing unnecessary code; prefer
  reusing and deleting over adding.
- Never implement, edit, or run against a file without first reading its current
  contents — no changes from assumption.

## Conventions
- Python: run and manage with `uv` (`uv run`, `uv add`).
- Commits: English, a few simple lines, no AI/model credit.
- Chat: respond in Japanese.

## Memory (pi-tinymemory)
- Save progress with the `remember` skill at natural breakpoints — a task finished,
  before a big detour, before context fills — without being asked.
- When the session-start memory block says consolidation is due, run the `dream`
  skill before other work.
